# jspace 仪表盘

在 DSH 右侧栏常驻显示 jspace 透镜实验仪表盘：内嵌 `http://127.0.0.1:8904/` 的实时页面，打开即可看到当前进度。

## 行为

- 安装后，每个会话的右侧栏都会保留一个 `jspace` 标签页，内嵌仪表盘页面本身。
- 页面自身带 `<meta http-equiv="refresh" content="30">`，每 30 秒刷新；插件只负责内嵌，不读取、不复制、不缓存页面中的任何数字。
- 标签页打开时先探测 8904 服务（跨源 `HEAD`，服务端无需渲染页面）。服务在：显示内嵌页面；服务不在：整块替换为一行「8904 未运行」，旧页面与旧数字被卸载，不会继续显示。
- 服务恢复后，最迟在下一轮探测（服务离线时约 10 秒一次，在线时 30 秒一次）自动重新挂载内嵌页面。
- 关闭标签页或切换到其他标签页后，内嵌页面与探测一起卸载；再次打开会重新探测并加载最新页面。

## 依赖与限制

- 需要本机在 `127.0.0.1:8904` 运行仪表盘服务（例如 `experiment/sicc/dashboard_server.py --port 8904`）。插件不启动该服务，也不读取它的数据文件。
- 内嵌页面使用自己页面的样式与字体，不继承 DSH 的主题、明暗模式和语言。
- 不写任何配置；只由 DSH 的右侧栏布局持久化标签页位置。
- 卸载插件时只关闭本插件的 `jspace` 标签页，其他标签页与右侧栏内容不受影响。
